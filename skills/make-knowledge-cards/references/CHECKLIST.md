# 质检清单

这份文件不参与生成，只参与质询。用途有两个：

1. **生成后自检**（机械字符串检查）——模型在给出卡片前对着第一部分过一遍。
2. **人工复核**（判定门槛）——输出后想追问"这张卡该不该拆、边界有没有跑掉"时，对着第二部分走一遍。

它不写成逐条硬性指令，是因为让模型在生成时同时完成"写卡"和"自我论证"，会显著拉长输出、提高截断风险，并挤占真正需要判断的注意力。

---

## 一、机械自检（字符串比对，零语义判断）

对着刚生成的卡片逐条核对。任何一条不通过，直接改，不要解释。

1. **锚点词都在原句里。** 对每张拆分卡：把 `锚点` 里的每个词单独拿去 `原文引用` 里找，必须逐个找到字面匹配。找不到就是源污染，退回原文重取。
2. **标题含完整锚点串。** 机制卡／对比卡的标题必须逐字包含整条锚点字符串——前置条件（如有）、实体、动作、对象，一个成分都不能少，且不能换成近义词。
3. **条件词没有丢在标题外。** 锚点里带前置条件时，标题里也要有；只写在锚点行里、标题里没有，等于读者顺着标题找不到条件。
4. **原文引用是原话。** 没改写、没拼接、没翻译。输出语言与原文语言不同时，引用仍保留原文。
5. **没有凭空多出的东西。** 这一遍里没有新增原文没有的例子、数字、实体、因果或结论；没有多出用户没要的自测题。
6. **限制没有脱钩。** 每条 `原文限制`／`适用条件` 仍挂在它限定的那张卡上，没有被单独搬走。
7. **声明了人工核对点。** 输出末尾有一句提示：`原文引用` 是给人抽查的。

**第 7 条不是形式。** 第 1–6 条比较的都是你自己写出来的字符串——提取锚点的模型、填引用的模型、判定"是否一致"的模型是同一个，带着同一份指令。如果它在提取那一步就把 `干扰` 写成了 `影响`，第 1、2 条会高高兴兴地判"一致"，因为 `影响` == `影响`。内部匹配只能保证卡片之间不失联，**不能保证忠于原文**。忠实度只有外部核对能发现，所以这一步必须留给人类，并且必须显式提示。

## 二、判定门槛（人工复核用）

### 门槛一：逻辑承载测试（它是不是不可替代的前提）

把这条信息替换成"某种条件／某个因素"，看核心主张是否还站得住。

- 替换后主张从"有依据的结论"塌成"无法理解的断言"——它承担了不可替代的推导功能。
- 替换后主张依然完整可理解——没过门槛，留在主张卡里当理解线索，**不拆**。

### 门槛二：语义自足测试（它自己是不是一个完整命题）

剥掉原文语境、只保留原文用词（严禁自己加词或推导动作）：

- 是自包含的完整命题（完整的主谓宾，且是明确判断）——过门槛。
- 只是孤立数据（`样本量N=100`）、日期（`2023年`）、或脱离上下文就读不懂的片段——不过门槛，**禁止拆卡**。

### 门槛三：认知单元上限（是否已经超出可读范围）

一条信息带来超过三层逻辑嵌套，或读它要跨过一屏——拆。
写进卡里只需一行就能说清——不拆。

### 机制 vs 边界（最容易搞反的一对）

- **机制**：把机制替换为"某种未明原因"后，因果推导断裂，或退化成纯断言——机制是独立知识节点，**拆卡**，并把关系名留在主张卡上。
- **边界／条件**：把它替换为"在所有情况下"后，主张变得绝对化、极端化，违背原文意图——它是主张的限定词，**合卡**，一旦拆出，主张卡就变成没有边界的大话。
- 机制卡拆出的充要条件（两条同时满足，缺一即合卡）：① 能脱离原主张独立构成"因为A，所以B"的完整因果命题；② 原文确实交代了它怎么运作，而不只是陈述了一个现象。
- 边界不拆不是例外：限定某条机制的边界，留在**那张机制卡**里；限定整体主张的边界，留在**主张卡**里。位置可以换个说法，但绝不能与它所限定的命题分离。

### 拆卡／合卡判定路径

- **删除测试**：把候选信息从段落里物理删掉，只看剩下的文字。剩文塌成空洞口号 → 承重墙，合卡；剩文依然自洽 → 装饰品／辅证，拆卡。
- **语法自足性**：单看候选信息是否主谓宾齐全。只是名词短语或从句 → 不独立，合卡。
- **去连接词检验**：候选信息前面挂着"例如／因为／但是／这就意味着"这类脚手架 → 抽掉脚手架它站不住，合卡。
- **语义重复 vs 语义增殖**：核心语义在原文别处已被表达过、只是同义反复 → 合卡；引入了原文别处没有的变量、现象或机理 → 拆卡。
- **泛化替代检验**：把候选替换成最抽象的泛指词，看原文逻辑是否还顺。
- **独立性测试**："这条信息离开原主张，还能不能回答一个独立问题？"能 → 拆；离开就不知所云（"反应速度提升了30%"）→ 合。
- **移花接木测试**："它能不能被借去支撑另一个不相干的主张？"能引用 → 通用件，拆；只能服务于原主张 → 专属零件，合。

### 写入规则（判定完之后）

- 拆卡时，写入的只能是原文用词。**允许**原样复制"农民想起绝收"；**禁止**顺手推导出"需要防范绝收"。
- 主张卡只留锚点与关系名（如"依据机制A的运作"），不展开推导；机制卡承载推导过程与相关边界。
- 模态词不升格：`可能导致` 不写成 `导致`，`与……相关` 不写成 `引发`，`作者认为` 不写成客观事实。锚点里的字取原文，不取你的概括。
